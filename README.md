## 📖 About

# Atlas

Atlas is a personal platform for planning, building and growing.

It brings together tools for fitness, career development, wedding planning and future projects in one modular dashboard.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Drace3r/forsemalm-hub.git
```

Navigate into the project

```bash
cd forsemalm-hub/client
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

## 🎯 Project Goals

This project has two main purposes.

- Build a productivity application that I can use in everyday life.
- Continuously improve my skills as a frontend and full-stack developer.

The application is intentionally built with scalability in mind, making it easier to introduce new features without large refactors.

---

## 📈 Development Philosophy

The project follows a few simple principles:

- Keep components small.
- Separate UI from business logic.
- Prefer reusable services over duplicated code.
- Build features instead of isolated pages.
- Refactor continuously instead of waiting until the end.
